# Retro Hub

A starter web app for the planned 90s–2000s interactive entertainment experience.

## Included
- Persistent music mini-player
- Games area
- Video area
- 🔴 Live Breaking News area
- Community posts
- Retro visual theme
- PWA manifest

## Add media
Put licensed audio/video assets in `media/` and update `app.js`.

## Live News
The Live News screen is intentionally a placeholder. Add an authorized live-news embed/feed from your chosen provider rather than scraping or rebroadcasting copyrighted streams.

## Publish
Upload these files to a GitHub repository with `index.html` at the repository root, then enable GitHub Pages from the repository's Pages settings using the `main` branch and root folder.
